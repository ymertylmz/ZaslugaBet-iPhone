# ZaslugaBet iPhone PWA v2

ÖNEMLİ: iPhone'da kurulum Safari üzerinden yapılmalı.

1. GitHub'da mevcut `ZaslugaBet-iPhone` reposuna bu paketteki dosyaları yükle ve eskilerin üstüne yaz.
2. GitHub Pages tekrar deploy olsun.
3. iPhone'da eski ZaslugaBet ana ekran ikonunu sil.
4. Safari'yi aç.
5. https://ymertylmz.github.io/ZaslugaBet-iPhone/ adresini Safari'de aç.
6. Paylaş → Ana Ekrana Ekle → Ekle.
7. Ana ekrandaki yeni ZaslugaBet ikonundan aç.

Chrome'dan eklenen eski kısayol tarayıcı arayüzüyle açılabilir.
